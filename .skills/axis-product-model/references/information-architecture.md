# AXIS 信息架构

## 推荐主导航

默认主导航：

```text
使用
线路
发布
运行
系统
```

## 使用

使用是默认首页和日常入口。

用户在这里完成：

- 查看这台设备现在能不能用。
- 复制本机代理地址。
- 开启或关闭虚拟网口。
- 切换当前使用线路。
- 应用当前更改。
- 根据提示补齐缺失配置。

## 线路

线路承载所有节点来源和线路组合。

用户在这里完成：

- 添加订阅。
- 添加单个代理。
- 添加其他 AXIS。
- 创建本机节点。
- 创建或编辑线路组合。
- 管理初始代理、落地出口、自动选择、容灾和健康检查。

## 发布

发布承载所有对外输出。

用户在这里完成：

- 发布 HTTP 代理。
- 发布订阅链接。
- 发布 AXIS 连接。
- 配置账号密码或等价认证。
- 控制访问范围。
- 复制连接信息。

## 运行

运行承载排障和状态查看。

用户在这里完成：

- 查看代理核心状态。
- 查看虚拟网口状态。
- 查看发布项状态。
- 查看最近错误和操作记录。
- 执行修复动作。

## 系统

系统承载低频管理能力。

用户在这里完成：

- 修改管理员密码。
- 管理高级配置。
- 管理核心版本。
- 管理宿主集成。

## 不推荐的信息架构

不要把以下技术对象默认并列为一级导航：

- 订阅与节点
- 出口线路
- 中转线路
- 本地代理
- 本机节点
- 运行状态
- 操作记录

这些对象应分别收敛到使用、线路、发布或运行中。
