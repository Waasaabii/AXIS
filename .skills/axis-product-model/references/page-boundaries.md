# AXIS 页面边界

## 使用页

应该做：

- 展示当前是否可用。
- 展示本机代理地址。
- 展示虚拟网口状态。
- 允许切换当前使用线路。
- 允许应用当前更改。
- 对缺失配置给出下一步按钮。

不应该做：

- 展开复杂节点来源管理。
- 重新实现线路组合逻辑。
- 创建发布认证规则。
- 展示过多高级协议参数。

## 线路页

应该做：

- 管理节点来源。
- 添加订阅。
- 添加单代理。
- 添加其他 AXIS。
- 创建本机节点。
- 组合线路。
- 配置初始代理和落地出口。
- 管理自动选择、容灾和健康检查。

不应该做：

- 负责对外发布账号密码。
- 承载本机日常复制代理地址的主流程。
- 展示运行日志作为主要内容。

如果产品已进入“首页 / 出口 / 规则 / 发布 / 诊断 / 系统”的信息架构，线路页职责应拆分到出口页和规则页，不应继续作为复杂对象集合页存在。

## 出口页

应该做：

- 管理节点来源。
- 添加订阅。
- 添加单代理。
- 添加其他 AXIS。
- 明确提供“创建本机节点”入口。
- 管理本机 VPS 出口。
- 管理出口池和出口标签。
- 展示出口健康状态。
- 允许本机节点创建后加入出口池。

不应该做：

- 承载自然语言规则主流程。
- 负责对外发布账号密码。
- 把创建本机节点隐藏在普通表单深处。

## 规则页

应该做：

- 管理直连、代理和出口选择规则。
- 展示自然语言规则。
- 展示 LLM 生成的规则草案。
- 支持测试、采用、调整和回退规则。
- 管理冷启动策略和运行后优化建议。

不应该做：

- 直接创建节点来源。
- 直接修改协议运行配置。
- 每次访问时调用 LLM 决策。

## 发布页

应该做：

- 创建 HTTP 发布项。
- 创建订阅发布项。
- 创建 AXIS 连接发布项。
- 配置认证。
- 复制对外连接信息。
- 查看发布项是否可用。

不应该做：

- 新增订阅或单代理。
- 重新编排线路路径。
- 替代使用页作为本机代理入口。

## 运行页

应该做：

- 合并运行状态和操作记录。
- 展示代理核心是否连接。
- 展示虚拟网口是否运行。
- 展示最近失败原因。
- 提供修复动作入口。

不应该做：

- 承载配置主流程。
- 修改线路组合规则。
- 创建发布项。

## 系统页

应该做：

- 管理管理员密码。
- 管理高级配置。
- 管理核心版本。
- 管理宿主集成。

不应该做：

- 承载日常使用流程。
- 混入节点来源管理。
- 混入线路编排主流程。

## 本机节点创建向导

本机节点创建向导归属于出口页的节点来源能力，不作为一级页面，但必须作为明确入口出现。

应该做：

- 让用户先选择创建目标：给自己用、给其他设备用、给其他 AXIS 用、作为默认出口或备用出口。
- 检测当前设备环境，包括宝塔/nginx、端口、域名、证书、TCP/UDP 可达性。
- 在可用时调用 LLM 生成创建方案草案。
- 让用户选择协议：HTTP、SOCKS、Trojan、Hysteria2。
- 让用户选择访问方式：通过宝塔/nginx 反向代理，或直接开放端口。
- 让用户选择监听地址：仅本机可访问，或允许其他设备直接访问。
- 让用户填写端口、认证信息和绑定线路。
- 创建前展示方案、风险和测试项。
- 测试通过并由用户确认后启用。
- 创建后加入节点来源和出口池。
- 创建后生成发布连接或发布草案。

不应该做：

- 默认承诺 Trojan 或 Hysteria2 一键公网可用。
- 把域名、证书、宝塔配置强制塞进 AXIS 的必填项。
- 把 Hysteria2 当作普通 HTTP 反向代理处理。
- 让 LLM 直接写入运行配置或直接启用节点。

## 宝塔/nginx 反代提示

当用户选择通过宝塔/nginx 反向代理时，页面应展示清晰的反代目标：

```text
请在宝塔或 nginx 中把域名反向代理到 127.0.0.1:端口
```

如果用户选择直接开放端口，页面应提示检查防火墙、云安全组、认证和端口暴露风险；如果协议是 Hysteria2，还应额外提示 UDP 端口可达性。
