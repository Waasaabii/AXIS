# AXIS 用户文案规则

## 基本原则

前端用户可见文案必须从用户视角表达：

- 用户能做什么。
- 用户会看到什么。
- 操作后的结果是什么。
- 出错后下一步怎么恢复。

不要暴露内部实现、技术分层、字段设计或工程命名。

## 推荐表达

- 添加节点来源
- 添加订阅
- 添加单个代理
- 添加另一台 AXIS
- 创建本机节点
- 创建一条线路
- 选择这台设备要使用的线路
- 开启虚拟网口
- 复制代理地址
- 发布给其他设备使用
- 生成订阅链接
- 生成 AXIS 连接
- 连接需要账号和密码
- 让当前更改生效
- 查看最近失败原因

## 避免表达

避免在用户可见文案中直接出现：

- provider
- egress group
- listener
- landing proxy
- transit route
- fallback group
- runtime reload
- config render
- controller
- 字段
- 权限
- 角色
- 模式
- 路由
- 入口
- 口径
- 前置
- 后置

## 错误提示

错误提示要说明用户下一步能做什么。

推荐：

- 当前线路暂时不可用，可以重新检测或切换到其他线路。
- 还没有节点来源，请先添加订阅、单个代理或另一台 AXIS。
- 连接信息已过期，请重新生成后再复制。
- 账号或密码不正确，请检查后重试。

避免：

- provider missing
- listener invalid
- runtime reload failed
- field required
- route not found

## 按钮文案

按钮优先使用动词短句：

- 添加订阅
- 创建线路
- 开启虚拟网口
- 复制连接信息
- 发布线路
- 重新检测
- 应用更改

## 本机节点与反代文案

推荐表达：

- 通过宝塔或 nginx 反向代理（推荐）
- 直接开放端口
- 仅本机可访问（推荐）
- 允许其他设备直接访问
- 请把域名反向代理到 127.0.0.1:端口
- 创建后会检查能否被其他设备连接
- Hysteria2 需要开放对应的 UDP 端口
- Trojan 需要可用域名、证书和 TCP 端口

避免表达：

- 一键创建公网节点
- 一键创建 Hysteria2 并保证可用
- 普通反代支持所有协议
- 自动配置宝塔
- 自动配置云安全组

错误或提醒推荐：

- 当前端口只允许本机访问，适合配合宝塔或 nginx 反向代理。
- 当前端口会直接暴露给其他设备，请确认已经设置账号和密码。
- Hysteria2 还需要 UDP 端口可访问，请检查系统防火墙和云安全组。
- 443 端口已被其他服务占用，可以换端口，或在宝塔/nginx 中配置转发。
