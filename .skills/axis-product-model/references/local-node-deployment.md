# 本机节点部署与宝塔反代

## 核心边界

本机节点是节点来源的一种。AXIS 负责创建本机服务、监听地址、端口、认证、绑定线路和可用性检查；域名、HTTPS 证书和统一公网入口可以交给宝塔或 nginx 管理。

推荐默认部署边界：

- 宝塔/nginx 负责域名、证书、443 统一入口、反向代理和外部访问控制。
- AXIS 负责本机端口、协议服务、认证信息、线路绑定和连接信息生成。

## 访问方式

创建本机节点或发布线路时，应提供访问方式选择：

- 通过宝塔/nginx 反向代理（推荐）。
- 直接开放端口。

### 通过宝塔/nginx 反向代理

默认监听地址应为 `127.0.0.1`。

AXIS 只要求用户填写本机端口，例如 `39001`，并展示反代目标：

```text
请在宝塔或 nginx 中把域名反向代理到 127.0.0.1:39001
```

这个方式适合：

- 希望统一使用 443 入口。
- 希望证书和域名都由宝塔/nginx 管理。
- 不希望 AXIS 端口直接暴露到公网。

### 直接开放端口

监听地址可由用户选择 `0.0.0.0`。

AXIS 必须提示用户确认：

- 防火墙已放行端口。
- 云安全组已放行端口。
- 对外连接已配置认证。
- Hysteria2 还必须放行 UDP 端口。

## 监听地址

监听地址必须由用户可控，但默认值应保守：

- `127.0.0.1`：仅本机可访问，适合宝塔/nginx 反代，默认推荐。
- `0.0.0.0`：允许其他设备直接访问，需要用户确认安全边界。

不要把监听地址文案写成工程配置项。前端推荐表达：

- 仅本机可访问（推荐）。
- 允许其他设备直接访问。

## 协议适配

### HTTP / SOCKS

HTTP 和 SOCKS 本机节点可以接近一键创建。

AXIS 可以自动生成：

- 端口。
- 账号密码。
- 绑定线路。
- 连接信息。

### Trojan

Trojan 可以快速生成配置，但不能承诺无条件一键可用。

必须考虑：

- 域名是否可访问。
- TLS 证书是否可用。
- TCP 端口是否开放。
- 如果通过宝塔/nginx，可能需要 TCP stream 或兼容转发方式，不应默认当作普通 HTTP 反向代理。

### Hysteria2

Hysteria2 可以快速生成配置，但不能承诺无条件一键可用。

必须考虑：

- UDP 端口是否开放。
- 云安全组是否允许 UDP。
- 系统防火墙是否允许 UDP。
- TLS/证书或协议要求的安全参数是否可用。

普通宝塔 HTTP 反向代理不适合 Hysteria2。Hysteria2 应默认按 UDP 端口直连或专门 UDP 转发处理。

## 可用性检查

AXIS 创建本机节点后，应检查并展示：

- 本机端口是否正在监听。
- 监听地址是 `127.0.0.1` 还是 `0.0.0.0`。
- TCP 端口是否可达。
- Hysteria2 的 UDP 端口是否可达。
- 如果用户填写外部域名，域名是否解析到当前 VPS。
- 如果用户配置证书，证书是否存在、未过期且匹配域名。

检查结果必须给出下一步建议，不应只显示失败代码。

## VPS 验证样例

测试服务器 `156.239.242.45` 的验证结论：

- Ubuntu 22.04。
- TCP `80`、`443`、`39000-40000` 可达。
- `443/tcp` 当前被 nginx 占用。
- 放行 `39001/udp` 后，外部 UDP 测试成功收到回包 `axis-udp-ok`。
- 结论：可以跑 Hysteria2，前提是保留对应 UDP 防火墙规则；也可以跑 Trojan，但若使用 `443/tcp` 需要处理 nginx/宝塔占用。

速率样例只可作为参考：该 VPS 对外下载约 `16-18 Mbps`，不等同于真实代理速率。
